# Data Structures — Unit 1 Case Studies

This repository contains two Unit 1 case studies with Python examples.

## Case studies

1. **E-commerce Product Sorting using Divide and Conquer** — Merge Sort is used to arrange sample products by price.
2. **Calendar Event Selection using a Greedy Strategy** — the activity-selection algorithm chooses a set of non-overlapping events.

## Folder contents

- `Unit-1/Case-Study-1-Ecommerce-Sorting.md` — first case study
- `Unit-1/Case-Study-2-Calendar-Greedy.md` — second case study
- `Unit-1/ecommerce_product_sorting.py` — Merge Sort program
- `Unit-1/calendar_activity_selection.py` — activity-selection program

## Run the programs

You need Python 3.8 or newer. No extra packages are needed.

```bash
python Unit-1/ecommerce_product_sorting.py
python Unit-1/calendar_activity_selection.py
```

If your computer uses `python3`, replace `python` with `python3`.

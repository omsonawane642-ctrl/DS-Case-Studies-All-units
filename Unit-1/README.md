Unit 1 – Data Structures Case Studies

This folder contains two Data Structures case studies with Python implementations for Computer Engineering students.

Case Study 1: E-commerce Product Sorting

Demonstrates the Divide and Conquer strategy using the Merge Sort algorithm to sort products by price.

Case Study 2: Google Calendar Event Selection

Demonstrates the Greedy strategy using an activity-selection algorithm to select non-overlapping events.

Files Included

- "Case-Study-1-Ecommerce-Sorting.md" – First case study report.
- "Case-Study-2-Calendar-Greedy.md" – Second case study report.
- "ecommerce_product_sorting.py" – Python implementation of Merge Sort.
- "calendar_activity_selection.py" – Python implementation of activity selection.

Requirements

- Python 3.8 or newer.
- No additional Python libraries are required.

How to Run

python ecommerce_product_sorting.py
python calendar_activity_selection.py

Note: The calendar example is a simplified educational activity-selection model, not Google's actual internal scheduling algorithm.

# Unit 1

This folder contains two Data Structures case studies.

| Topic | Algorithm | Python file |
|---|---|---|
| E-commerce product sorting | Merge Sort (Divide and Conquer) | `ecommerce_product_sorting.py` |
| Calendar event selection | Activity Selection (Greedy) | `calendar_activity_selection.py` |

Run either program with Python:

```bash
python ecommerce_product_sorting.py
python calendar_activity_selection.py
```

Both programs use built-in Python features only.

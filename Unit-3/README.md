Unit 3: Stack and Queue Using Linked Lists

Introduction

In this case study, I have implemented stack and queue operations using linked lists in Python. Both are linear data structures, but they work differently. A stack follows LIFO (Last In, First Out), while a queue follows FIFO (First In, First Out).

Aim

To implement stack and queue operations using linked lists and understand how these operations work.

Objectives

- To understand the concept of linked lists.
- To implement stack operations using a linked list.
- To implement queue operations using a linked list.
- To perform insertion, deletion, display, and peek operations.
- To study the time complexity of these operations.

Files Included

1. "Case-Study-Stack-Queue-Linked-Lists.md" – Contains the complete case study report.
2. "stack_queue_linked_lists.py" – Python program for stack and queue operations.

Operations Performed

Stack

- Push: Adds an element to the stack.
- Pop: Removes the top element.
- Peek: Displays the top element without removing it.
- Display: Shows all elements in the stack.

Queue

- Enqueue: Adds an element to the queue.
- Dequeue: Removes the first element.
- Peek: Displays the front element.
- Display: Shows all elements in the queue.

Technologies Used

- Python
- Linked List
- Data Structures

How to Run

python stack_queue_linked_lists.py

Conclusion

Through this case study, I learned how to implement stack and queue operations using linked lists. The stack follows LIFO, and the queue follows FIFO. Linked lists allow elements to be added and removed without setting a fixed size in advance.

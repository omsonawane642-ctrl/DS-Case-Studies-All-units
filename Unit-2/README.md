Case Study: Social Network Adjacency Matrix

Introduction

In this case study, I have studied how friendship connections in a social networking application can be represented using an adjacency matrix. In this method, each user is represented as a vertex, and a friendship between two users is represented by an edge.

Aim

To study and implement an adjacency matrix for representing friendship connections in a social network using Python.

Objectives

- To understand graph representation using an adjacency matrix.
- To represent users and their friendship connections.
- To check whether two users are friends.
- To understand the time and space complexity of an adjacency matrix.

Files Included

1. "Case-Study-Social-Network-Adjacency-Matrix.md" – Contains the complete case study report.
2. "social_network_adjacency_matrix.py" – Python program to create and display the adjacency matrix.

Technologies Used

- Python
- Graph data structure
- Adjacency matrix

How to Run the Program

Make sure Python is installed on your computer. Open a terminal in this folder and run:

python social_network_adjacency_matrix.py

Conclusion

Through this case study, I learned how an adjacency matrix can be used to represent friendship connections. It provides a quick way to check whether two users are connected. However, it requires a large amount of memory when the number of users increases, so other graph representations may be more suitable for large social networks.

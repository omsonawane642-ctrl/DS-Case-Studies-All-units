# Unit 5: Graph Algorithms and Huffman Coding

This unit contains two case studies related to important data structures and algorithms.

## Case Study 1: GPS / Navigation System Using a Weighted Graph
A city map is represented as a weighted graph. Places are vertices, roads are edges, and road distances are weights. The Python program uses Dijkstra's algorithm to find the shortest route between two places.

Folder: `GPS-Navigation-Weighted-Graph/`

## Case Study 2: ZIP/GZIP File Compression Using Huffman Coding
This case study explains how frequency-based encoding and a Huffman tree can reduce the number of bits needed to represent data. The Python program builds a Huffman tree and encodes/decodes sample text.

Folder: `Huffman-File-Compression/`

## How to Run
Install Python 3, then run the program from its folder:

```bash
python gps_navigation.py
python huffman_compression.py
```

The programs use small sample data for learning. They are educational examples and are not full GPS or ZIP/GZIP implementations.

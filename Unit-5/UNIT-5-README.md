# Unit 5: Graph Algorithms and Huffman Coding

This folder contains two student-level case studies:

1. **GPS / Navigation System:** represents a small city map as a weighted graph and uses Dijkstra's algorithm to find a shortest route.
2. **ZIP/GZIP Compression Using Huffman Tree:** demonstrates frequency counting, Huffman tree construction, encoding, and decoding.

## Folder Contents
- `GPS-Navigation-Weighted-Graph/` — report and Python program for shortest-route finding.
- `Huffman-File-Compression/` — report and Python program for Huffman coding.
- `README.md` — this overview.

## Running the Programs
Use Python 3 and run each script from its own folder:

```bash
python gps_navigation.py
python huffman_compression.py
```

**Note:** Both programs are educational examples. The navigation program uses fixed sample distances. The Huffman program demonstrates Huffman coding only; it does not produce actual ZIP or GZIP archives.
